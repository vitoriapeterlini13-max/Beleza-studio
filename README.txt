# Beleza Studio — site

## Como abrir no VS Code
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html` com o Live Server.
4. O site é responsivo para celular e computador.

## MUITO IMPORTANTE: personalize
Abra `script.js` e altere:
- `WHATSAPP` → coloque o número real, com DDI + DDD e sem espaços.
- `INSTAGRAM` → coloque o Instagram real.
- `FACEBOOK` → coloque o Facebook real.

Exemplo:
WHATSAPP = "5514991234567";

As fotos estão usando imagens online como demonstração. Para o site real, substitua as URLs no `style.css` pelas fotos reais dos trabalhos da profissional.

## Observação
Os preços exibidos são apenas exemplos e devem ser trocados pelos preços reais.
